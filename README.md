## Delete Feature

Tap a city to edit it, then press **DELETE CITY**, or long-press any city in the list. A confirmation dialog appears, and confirming removes the city's document from the Firestore `cities` collection. The list is driven by a Firestore snapshot listener, so additions, edits and deletions persist across app restarts.
